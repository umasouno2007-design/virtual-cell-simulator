# 虚拟细胞能量代谢模拟器

一个适合 Python 初学者继续修改的 Streamlit 教学项目。用户可以加入葡萄糖、补充氧气、增加线粒体，并观察 ATP、健康度和乳酸随时间变化。V0.2 新增实验参数、预设场景、CSV 导出和云端部署准备。

## 功能

- 单步运行或一次连续运行 5–100 步
- 葡萄糖、氧气、ATP、健康度、乳酸、线粒体和时间状态
- 缺氧、无氧代谢、乳酸堆积和细胞死亡机制
- 简化细胞图、数值、进度条与历史曲线
- 所有状态都有上下限；死亡后自动停止模拟
- 4 个实验预设：正常环境、急性缺氧、高能量需求、线粒体丰富
- 可调 ATP 消耗、代谢产率、缺氧阈值、乳酸速率和资源补充量
- 将完整历史记录下载为 CSV
- 响应式布局，可在部署后使用 Pad 浏览器访问

## 环境要求

- Python 3.10 或更高版本
- Streamlit、pandas、matplotlib（见 `requirements.txt`）

## 安装与运行

在项目目录中执行：

```bash
pip install -r requirements.txt
streamlit run app.py
```

命令执行后，浏览器通常会自动打开；若没有，请访问终端显示的本地地址。

## 模拟规则

1. 氧气充足时，细胞消耗葡萄糖和氧气，通过线粒体高效率地产生 ATP。
2. 氧气低于阈值时，模型切换为无氧代谢：ATP 产量下降，乳酸增加。
3. 每一步都会消耗维持细胞活动所需的 ATP。
4. ATP 过低或乳酸过高会降低健康度；资源状态良好时可缓慢恢复。
5. 健康度降到 0 后，细胞死亡，模拟停止。
6. 线粒体越多，有氧代谢容量越高，但最多 12 个，并带来少量维护成本。

## 教学简化说明

这个项目展示的是因果关系，不是科研级定量模型。葡萄糖、氧气、ATP、乳酸均使用相对单位；反应速率、阈值和 ATP 产率是人为设定的教学参数。真实细胞还涉及复杂的酶动力学、细胞区室、底物转运、反馈调节与多条代谢通路。本程序不可用于医疗或实验预测。

## 修改建议

初学者可以先在 `cell.py` 中调整初始值、阈值和反应速率，再观察曲线变化。添加新变量时，应同时更新 `Cell`、`snapshot()`、界面指标和曲线。

## 在 Pad 上使用

Pad 不需要本地安装 Python。先把本项目上传到 GitHub，再按 `DEPLOYMENT.md` 部署到 Streamlit Community Cloud；部署成功后，在 Pad 浏览器打开生成的网址即可。
