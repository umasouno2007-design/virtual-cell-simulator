# 示例与用户数据

## 教学合成数据

`a549_teaching_synthetic.csv` 是为测试 e-cell 的“导入—对齐—粗校准—留出验证”流程而制作的**教学合成数据**。它不是湿实验结果、公开数据库下载数据或患者数据。数值以 A549 的默认培养设置为背景，加入固定的、预先写入的数据偏移，目的是让验证脚本可重复运行并能报告非零误差。

该文件可公开分发；它不能用于推断 A549 的真实生长率、摄取率、药物反应或任何临床结论。

## CSV 格式

首列必须为时间，推荐使用 `time_h`（小时）。可选列及单位：

| 列名 | 含义 | 单位 |
| --- | --- | --- |
| `viable_cells` | 活细胞数 | cells |
| `viability_percent` | 存活率 | % |
| `glucose_mM` | 葡萄糖 | mM |
| `lactate_mM` | 乳酸 | mM |
| `pH` | 酸碱度 | 无量纲 |
| `oxygen_percent` | 氧/溶氧代理 | % |

应用会接受常见中文或英文别名，详见 `experiment_data.py`。每个文件应对应一个已明确记录的细胞系、接种量、培养容器、体积、培养基、环境及采样方案；混合批次或未注明单位的数据不应直接用于校准。最低建模条件至少包括两个可用时间点和一种可比较指标；若要报告留出误差，建议预先留出后段或独立批次的多个时间点。时间必须是从实验起点开始的非负小时，负浓度、超过 100% 的存活率、重复时间与无法识别单位会被阻止或警告。通过格式检查不等于实验设计或生物学结论有效。
